## 5. 决策与坑记录

- **香港/海外服务器不可用**：企微对「接收消息服务器URL」和「可信域名」**都**强制校验域名备案主体，
  而 ICP 备案要求大陆境内服务器+接入商 → 香港机器备不了案 → 企微一个接口都调不了。
  官方文档 `path/90930` 未提此限制，是实测撞出来的。
- **选服务器先测到企微 API 的延迟**：回调处理同步串行 4 次企微调用，要挤进 1 秒窗口。
  实测 AWS 香港 50ms / DMIT 香港 57ms / 腾讯云上海 88ms / DMIT 美国 **490ms（必超时）**。
- **前端已 host 无关化**：`sys.config` 的 production 是兜底环境，`BASE_API` 运行时按
  `location.origin` 拼接，所以**备案后换域名不需要重新打包**，只改 `.env` 的 `PUBLIC_BASE`。
- **值得做但没做**：给 `IYqueCustomerInfoServiceImpl#addCustomerCallBackAction` 加 `@Async`
  （同文件 536 行已有先例），改成立刻回 `success` 再异步处理。可根治回调超时与重推。
- **域名后缀**：`.cn` / `.com` 优先。`.top`/`.xyz` 虽可备案但微信风控严，
  H5 页面被拦对 SCRM 是致命的。
